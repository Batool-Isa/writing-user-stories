Instagram Login Feature

A. Save credentials

As an Instagram user, I want to save my credentials so I can log in easily.

1. GIVEN the user already logged in once, WHEN they enter the app again, THEN their account should be saved.
2. GIVEN the account is saved, WHEN the user opens Instagram, THEN they can select their account without entering their credentials again.

B. Reset password

As an Instagram user, I want to reset my password using my email so I can log in easily if I forget my password.

1. GIVEN the user forgot their password, WHEN they click "Forgot password?", THEN they can enter their email.
2. GIVEN the email is connected to an account, WHEN the user submits it, THEN they should receive a password reset link.
3. GIVEN the user receives the reset link, WHEN they open it, THEN they can create a new password.

C. Login with email or username

As an Instagram user, I want to log in using my email or username so I can log in easily if I forget my username.

1. GIVEN the user is on the login page, WHEN they enter their username and password, THEN they should be able to log in.
2. GIVEN the user is on the login page, WHEN they enter their email and password, THEN they should be able to log in.
3. GIVEN the user enters the wrong information, WHEN they try to log in, THEN an error message should appear.

D. Login with more than one account

As an Instagram user, I want to be able to log in with more than one account so I can switch between my accounts easily.

1. GIVEN the user is logged in, WHEN they choose to add another account, THEN they should be able to log in to another account.
2. GIVEN the user has more than one account, WHEN they select an account, THEN Instagram should switch to that account.
3. GIVEN the user has multiple accounts saved, WHEN they open Instagram, THEN they should be able to choose which account to use.

E. Log out

As an Instagram user, I want to log out easily so I can keep my account safe and secured.

1. GIVEN the user is logged in, WHEN they click log out, THEN they should be logged out.
2. GIVEN the user clicks log out, WHEN the confirmation appears, THEN they can confirm or cancel.
3. GIVEN the user logged out, WHEN they open Instagram again, THEN they should see the login page.
